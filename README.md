# 看见音乐

看见音乐之美。一个极简音乐可视化网站，上传音乐或粘贴链接，就能把声音实时转成可观看、可录制、可分享的动态视觉。

## 功能

- 上传本地音频文件
- 读取 mp3、wav、ogg、m4a 等音频直链
- 通过本地解析服务读取公开视频页面里的音频
- 播放时实时分析低频、中频、高频能量
- 十一种视觉模式：光谱圆环、波形隧道、光幕雕塑、星河声线、声波地貌、激光厅、光环扫描、声波漩涡、线场雕塑、迷幻流体、晶体星尘
- 三种色彩主题：极光、炽热、黑金
- 中英文界面切换
- 沉浸模式隐藏界面控件，全屏欣赏视觉
- 灵敏度调节
- 录制当前画布并导出 WebM 视频
- 下载按钮会在停止录制并生成视频后出现

## 对外展示

推荐通过 Node.js 服务部署，这样既能展示网站，也能支持 YouTube、B 站等公开视频页面链接解析。

```bash
npm run start
```

默认访问地址：

```text
http://localhost:4177
```

项目已包含：

- `render.yaml`：Render 一键部署配置
- `site.webmanifest`：网站安装信息
- `favicon.svg`：站点图标
- `robots.txt`：搜索引擎访问声明

## 使用方式

### 基础模式

1. 用浏览器打开 `index.html`
2. 选择一首音乐，或粘贴可直接播放的音频链接
3. 点击播放器播放
4. 切换视觉模式或调节参数
5. 点击“开始录制”，再次点击停止后下载视频

### 视频链接解析模式

1. 确保本机已安装 `yt-dlp`
2. 在项目目录运行 `npm run start`
3. 打开 `http://localhost:4177`
4. 粘贴 YouTube、B 站等视频页面链接并读取

## 链接说明

静态页面只支持可直接播放的音频文件链接。YouTube、B 站等页面链接需要本地服务解析真实音频流；当前通过 `server.js` + `yt-dlp` 实现。

GitHub Pages 公开版属于静态页面，可以用于展示、上传本地音频和读取音频直链；如果要解析 YouTube、B 站等平台链接，需要运行本地服务，或单独部署一个支持 `server.js` 的后端服务。
